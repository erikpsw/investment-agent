# 浏览器检修与修复（2026-10-01）

检查已登录本地网页的自选股和投资组合，使用 390 × 844 手机视口。

## 发现与修复

- 投资组合出现 Not Found：后端遗漏 Token 路由注册；注册后发现 PostgreSQL 5 位小数时间戳在 Python 3.10 下解析失败，一并修复。真实接口复查返回 200。
- 首次持仓加载会获取所有标的历史研究：增加兼容的 include_research 参数，前端只请求估值；走势、财报、新闻通过各持仓的个股入口查看。
- 保存会触发完整分析和再次加载：保存只更新持仓及估值，分析独立运行。
- 投资组合行情重复获取：接入市场感知的报价缓存，批量读取及写入，缺失行情并行获取，不缓存供应商错误。
- 手机操作按钮拥挤：改为两列、至少 44 像素触控区域，减少页面边距，折叠 MCP 设置，增加空状态、错误重试和实际请求耗时。
- 保护修改：有未保存修改时禁用刷新；保存、加载期间禁用编辑；加载失败禁止保存空列表覆盖云端持仓；修改后清除旧分析。
- 自选股列表报价停留后不刷新：当前分组每 60 秒刷新，隐藏页面暂停，重新显示补刷，支持手动刷新，不请求全市场研究。

## 本地测量

真实账户 10 条持仓，缓存接入前重复刷新 7.31 秒，接入后重复刷新 3.20 秒。自选股报价一次请求 2.65 秒，分组同步 2.33 秒。
这些是开发环境单次测量，仍包含认证、云端存储、行情与汇率耗时；首次加载仍可能较慢，不能视为稳定延迟保证。

- 浏览器回归：10 项通过，覆盖自选股自动/手动刷新、手机分组、详情刷新、A/港/美财报新闻、长历史及估值、组合保存和失败保护。
