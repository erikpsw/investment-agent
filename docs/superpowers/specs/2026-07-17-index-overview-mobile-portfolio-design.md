# 指数市场概览与移动端投资组合设计

## 目标

扩展首页市场概览，使其覆盖 A 股、港股和美股主要指数并支持进入独立走势页；同时改善手机端投资组合编辑体验，并从投资组合页移除“A 股热门 ETF 板块”展示。

## 范围

### 投资组合页

- 移除“A 股热门 ETF 板块”组件及其一键填入入口。
- 保留 ETF 搜索能力，ETF 与股票继续通过同一个代码/名称搜索框加入持仓。
- `md` 及以上断点保留现有表格布局。
- `md` 以下断点使用“一只持仓一张卡片”的布局。
- 手机卡片包含：代码/名称搜索、名称、市场、币种、数量、买入均价、现价、市值、浮盈亏、盈亏比例、备注和删除操作。
- 代码搜索和备注使用整行宽度；市场/币种、数量/买入均价使用双列布局；现价、市值和盈亏为只读指标。
- 搜索下拉框宽度不得超出手机视口，并保持足够高度显示候选列表。

### 市场概览

首页展示九个主要指数：

- A 股：上证指数、深证成指、创业板指、沪深 300。
- 港股：恒生指数、恒生科技指数。
- 美股：标普 500、纳斯达克综合、道琼斯工业指数。

每个指数返回以下字段：

- `code`：行情数据源使用的代码。
- `name`：中文展示名称。
- `market`：`CN`、`HK` 或 `US`。
- `history_ticker`：历史走势接口使用的 Yahoo Finance 代码。
- `price`、`change`、`change_percent`：当前行情。

A 股实时行情沿用腾讯行情源；港股与美股指数使用现有 Yahoo Finance 客户端。各数据源独立容错：单个指数或单个市场失败时保留其他可用指数，不让整个市场概览失败。

## 指数详情页

- 市场概览卡片链接到 `/market/index/[ticker]`，路径参数使用 URL 编码后的 `history_ticker`。
- 详情页使用现有历史行情 API 和 `CandlestickChart`，不展示个股财务指标。
- 提供固定周期：5 日、1 月、3 月、6 月、1 年。
- 页面显示中文指数名、市场、最新点位、涨跌额和涨跌幅，并提供返回首页入口。
- 历史数据失败或为空时显示明确的空状态，不影响页面其他信息。

## 数据流

1. 首页请求 `/api/market/overview`。
2. 后端聚合腾讯 A 股指数和 Yahoo 港美指数，标准化为统一 `MarketIndex`。
3. 前端按 `market` 分组或按固定顺序渲染可点击卡片。
4. 用户点击卡片后，详情页使用 `history_ticker` 请求 `/api/history/{ticker}`。
5. 周期切换只重新请求历史数据，不重新加载整个页面。

## 错误处理

- 单个指数获取失败时跳过该指数，并继续返回其他结果。
- 市场概览没有任何可用数据时沿用现有错误/空状态。
- 详情页的报价和历史走势分别处理错误；其中一个失败时仍展示另一个可用部分。
- 移动端搜索候选下拉框根据视口计算宽度和左边界，避免横向溢出。

## 测试与验收

- 后端单元测试覆盖九个指数、市场与历史代码映射，以及单一数据源失败时的降级行为。
- 前端测试覆盖指数详情链接的 URL 编码和认证既有测试不回归。
- `npm run lint` 无新增错误，`npm run build` 成功。
- Python 测试套件通过。
- 桌面端投资组合仍显示表格；手机端不显示横向表格，每只持仓独立成卡。
- 投资组合页不再显示“A 股热门 ETF 板块”，但搜索结果仍可选择 ETF。
- 首页九个指数卡片可点击，详情页五个周期均可切换并显示走势或明确空状态。

## 非目标

- 不删除 ETF 后端接口、扫描任务或搜索索引。
- 不改动投资组合存储结构、PAT/MCP 权限和 Auth0 登录流程。
- 不增加分时图、实时推送或新的行情供应商。
