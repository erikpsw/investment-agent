# 个股页操作与布局修复

## 布局

- 默认 K 线高度从固定 400px 改为 `clamp(200px, 32dvh, 300px)`；ResizeObserver 同步宽高，调整视口不重建图表。
- 网格允许收缩，修复桌面切换手机后画布导致的横向溢出；保留 5 年、10 年、全部历史及 MA20。
- 财报原文放入财务历史区域，新闻列独立对齐顶部。
- 真实 KLIC 页面、1413 × 871 视口：画布约 279px，无横向溢出，财报原文位于财务历史中。

## 操作

- 顶部星标和快捷操作的添加自选都打开分组对话框，显示层级路径，用户明确选择分组后才能提交。
- 支持加载错误重试、提交错误重试、重复添加提示、空分组创建入口和登录返回路径。
- 分享按钮复制个股链接并反馈成功或失败。
- 刷新按钮更新行情、历史图表、估值、财务历史、新闻与披露列表，避免重复提交。
- 修正成交额和市值在前端再次乘单位的错误；零涨跌显示为零。
