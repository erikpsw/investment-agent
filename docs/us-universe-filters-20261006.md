# 美股目录与条件筛选

## 行为

从 Nasdaq Trader 官方 Nasdaq / 其他交易所目录核验普通股、普通股票 ADR 和有明确股票类型的 REIT。排除 ETF、基金、优先股、权证、债券、单位、测试及未核验证券；不包含 OTC。

定时任务逐批请求所有入池股票的腾讯美元报价。原始报价时间使用美国东部时区；保留原始日期，不能把抓取时间当作报价时间。腾讯覆盖不足时尝试完整东方财富分页行情；任何采集失败不覆盖已有文件。目录或报价超过七天，接口明确报错，不降级回活跃前100只。

本轮真实采集：官方目录 13,289 条证券，股票类型筛选后 5,412 只；请求 109 批，有效行情 5,175 只，缺少有效行情 237 只。

## 条件与评分

美股筛选支持市值上下限（亿美元）、股价上下限（美元）、最低成交额（百万美元）及上市交易所。多条件 AND，缺失指标不能满足有效阈值。默认市值至少10亿美元、股价至少5美元、成交额至少100万美元。取消条件明确传0关闭最低阈值，最高值留空取消。

所有有效行情先过滤，再取成交额前120只补算历史并按现有公式排序，页面展示目录、行情覆盖、条件匹配和本轮评分数。当前默认条件匹配2,324只；120只是历史评分预算，不是扫描池大小。结果列显示价格、市值和成交额，并标明本币。

AI 自然语言筛选复用完整美股行情池，所有快照条件先覆盖全部有效报价；历史评分也限制120只，并显示尚未进行历史匹配/评分的数量。冻结研究引擎、旧报告和公式权重未改变。
