# 手机自选股优化与实测（2026-10-01）

## 实测环境

本机 Next.js 开发服务，用户已登录的 Codex 浏览器，390×844 手机视口。通过浏览器 Performance API 记录请求时间，未复制登录凭据。下列是单次实测，不是统计分位数；认证、云数据库、行情源和本机编译都会影响时间。

| 场景 | 实测 |
|---|---:|
| 优化前页面 DOM 就绪 | 207ms |
| 优化前分组树请求 | 3052ms |
| 优化前重复研究预取 | 2969ms、1411ms |
| 中间版本冷报价（4只ETF，逐只缓存写入） | 12447ms |
| 中间版本电子分组报价（20只） | 8811ms |
| 批量优化后电子分组冷请求（20只） | 4771ms |
| 已有缓存时电子分组再次进入 | 2225ms |
| 真实长电科技详情首次请求 | 5510ms |
| 随后的详情自动更新，页面记录 | 3500ms |

电子分组同一20只报价从8.81秒降至4.77秒，约减少46%；再次进入约2.23秒。仍保留每次请求的认证校验。优化后进入列表不再自动发起整批研究请求，分组树与报价只各发起一次。报价更新、分组同步、详情更新时间及耗时均显示在页面。

## 手机交互

- 首屏先展示股票；长分组树移入底部选择器，支持搜索、市场筛选、数量显示与选择后自动收起。
- 记住用户上次分组；桌面保留可折叠分组树。
- 股票卡片整张可点击，显示名称、代码、现价和涨跌；支持本组搜索和涨跌排序。
- 分组管理与添加股票默认折叠。详情中支持备注、移出自选。
- 详情占满手机宽度，走势图默认展开；提供44px返回按钮和触屏周期按钮。
- 走势图按需加载；删除后台批量研究预取；合并并发获取 access token 的请求。
- 同一用户分组读取增加10秒缓存，保存后立即替换，容量128个账户并返回数据副本。
- 报价缓存批量写入；持久缓存失败后60秒退避；腾讯批量报价优先，只对缺失股票回退，并行处理最终回退。

## 验证

Python tests/：110 passed。前端界面、认证、指数检查：29 passed。浏览器回归覆盖立即更新、60秒刷新、关闭停止、60个分组搜索、首屏股票、无横向溢出、手机全宽详情及返回按钮。生产构建和类型检查通过。

浏览器人工验证使用真实登录账户，未执行账户数据写入。自动化测试使用隔离模拟账户。未提交、推送或部署。根目录旧集成脚本依赖缺失的 investment.viz，历史限制见 local-optimization-20261001.md。
